# 문서 동기화

1. `docs-syncer` 에이전트에게 위임한다. 인자로 범위가 주어지면($ARGUMENTS) 그 문서/기능만 보게 한다.
2. 결과를 사용자에게 보여준다. 수정된 문서는 `git diff docs/` 로 확인시킨다.
3. 사용자가 확인하면 `docs:` 커밋을 만든다.
4. "기획과 구현 불일치" 항목이 있으면 코드가 틀렸는지 기획이 바뀐 건지 사용자에게 물어본다.
   - 기획이 바뀐 거라면 `docs/기획.md`·`docs/DOMAIN.md` 중 해당 문서를 고치고 커밋 메시지에 `(기획 변경)` 을 붙인다 — 팀원이 알아야 하므로 PR 본문에도 적는다.
