# core 컨벤션 검토 (2026-09-30)

`core/docs/`(ARCHITECTURE, CODE_STYLE, EXCEPTION, LOG, TEST)와 테스트 훅을 검토하면서 찾은 **상충하는 규칙, 모호하거나 naquiz와 맞지 않는 전제, 강제되지 않는 규칙**을 모았다. 항목마다 방향을 고르면, Claude가 이 문서를 바탕으로 컨벤션 문서·훅·설정을 고친다.

## 사용법

- 항목마다 선택지 하나를 `- [x]`로 체크한다. 여러 개를 함께 적용하려면 여러 개를 체크한다.
- 선택지에 없는 방향은 "기타"를 체크하고 `메모:` 뒤에 적는다. 선택지를 골랐더라도 덧붙일 말이 있으면 메모에 적는다.
- `(추천)`은 Claude의 제안일 뿐이다. 판단이 서지 않는 항목은 비워 두면 건드리지 않는다.
- 다 채우면 Claude에게 **"검토 문서대로 반영해줘"**라고 요청한다.
