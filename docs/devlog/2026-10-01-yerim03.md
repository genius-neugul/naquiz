## 결정한 것
- **훅은 shell form으로 등록하고 인터프리터를 앞에 적는다**: `args`가 있으면 exec form이라 셸 없이 파일을 직접 실행한다. Windows는 shebang을 읽지 못해서 EFTYPE으로 실패한다. `args`를 빼면 macOS는 `sh -c`, Windows는 Git Bash로 실행되어 양쪽에서 같은 설정이 동작한다. → [수정할 때](../../.claude/README.md#수정할-때)
- **Python은 `python3`로 고정하고 Windows PC에서 맞춘다**: macOS는 `python3`만 있고, Windows의 python.org 설치판은 `python`만 만든다. 동작하는 인터프리터를 골라 주는 실행기 스크립트도 검토했다. 하지만 팀은 2명이고 Windows는 이 PC뿐이라, 저장소를 단순하게 두고 Windows는 Store 판 Python을 설치하게 했다. → [처음 설정 > Windows](../../.claude/README.md#windows)
- **Windows Python 인코딩은 PC 환경 변수로 맞춘다**: Windows Python은 표준 입출력을 cp949로 처리해서, 가드의 한글 차단 사유가 UTF-8이 아닌 바이트로 나갔다. 저장소는 바꾸지 않고 사용자 환경 변수 `PYTHONUTF8=1`로 맞췄다. → [트러블슈팅 참고](../troubleshooting/2026-10-01-windows-훅-실행-실패.md#참고-windows-pc에서-따로-맞출-것)
