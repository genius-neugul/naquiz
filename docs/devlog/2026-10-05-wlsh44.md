- **PR 설명 아티팩트는 강제하지 않고 매번 묻는다.** PR 게이트 훅으로 막는 안은 문서·설정만 바뀐 PR에도 부담이 커서 버렸다. 초안은 에이전트가 테스트·리뷰와 병렬로 쓰고(메인 대화 컨텍스트 절약), 게시만 메인 대화가 한다(아티팩트 게시는 메인 대화만 가능). 초안과 링크는 `.git/claude-explain/`에 둬서 커밋되지 않고 같은 브랜치는 같은 링크로 갱신한다. → [pre-pr SKILL.md](../../.claude/skills/pre-pr/SKILL.md)
- **그림이 내용을 전하고 글은 읽는 법만 쓴다.** 섹션마다 그림 하나, 설명은 2문장 이하로 제한했다. 그림 안 이름은 코드에 있는 이름 그대로 쓰고, 코드와 문서가 다르면 그리지 말고 먼저 알리게 했다. → [SKILL.md 1. 사실 모으기](../../.claude/skills/explain/SKILL.md)
