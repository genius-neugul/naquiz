## 결정한 것
- **게임별 처리는 `RoundStartedHandler` 확장점으로 부른다.** 공통 흐름(게임 시작·다음 라운드)이 게임 패키지를 직접 참조하지 않게 하려고, 게임 종류를 지원하는 핸들러만 골라 부른다. 스무고개·노래도 같은 방식으로 붙인다. → [RoundStartedHandler](https://github.com/genius-neugul/naquiz/blob/9720148/core/game-api/src/main/java/geniusneugul/project/core/game/common/presentation/RoundStartedHandler.java#L7)
- **카운트다운 취소는 정리용이고, 콜백이 라운드를 다시 확인한다.** 취소와 실행이 엇갈릴 수 있어서, 늦게 도착한 스틸컷 공개는 방 락 안에서 라운드가 그대로인지 보고 막는다. → [StillCutRevealer.revealNext](https://github.com/genius-neugul/naquiz/blob/9720148/core/core-domain/src/main/java/geniusneugul/project/core/game/stillcut/implement/StillCutRevealer.java#L40)
- **진행 막대는 `requestAnimationFrame`으로 그리고 CSS 전환은 끈다.** 250ms 간격 갱신에 0.3초 전환이 겹쳐 막대가 끊겨 보였다. 막대가 없는 스무고개 차례 표시는 250ms 그대로 둬 불필요한 렌더를 막았다. → [useNow.ts](https://github.com/genius-neugul/naquiz/blob/9720148/front/apps/game/src/hooks/useNow.ts#L7)
- **`SolvedRound` 변환은 채팅 presentation에 둔다.** `SolvedRound.from(AnswerSolvedResult)`로 옮기면 game이 chat service를 참조해 도메인 순환이 생긴다. (미반영, 현재 구조 유지)
