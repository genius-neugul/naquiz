## 결정한 것
- 단서는 누르자마자 열지 않고 `CLUE_SELECTED` → 3초 → `CLUE_REVEALED`로 연다. 모두가 같은 칸에 집중하게 하려는 것이다. 3초 안에 정답이 나오면 공개하지 않고, 다음 차례는 공개 뒤 시작한다. → [기획.md 영화 스무고개](../기획.md), [DOMAIN.md 3-2 게임 애그리거트](../DOMAIN.md#3-2-게임-애그리거트)
- 10초 안에 안 고르면 차례만 넘기던(패스) 규칙을 남은 단서 중 무작위 공개로 바꿨다. 아무도 고르지 않아 라운드가 늘어지는 것을 막는다. 공개한 참가자는 시간이 지난 그 차례 참가자로 남긴다. → [API.md 실시간 메시지(STOMP) 규격](../API.md#실시간-메시지stomp-규격)
- 차례 상태(순서·현재 차례·고른 단서)는 스틸컷처럼 메모리의 `ClueBoard`에 두고 방 락 안에서만 바꾼다. 통계에 필요 없고 선착순·타이머와 같은 락으로 직렬화해야 해서다.
- `RevealedClue`는 `@ManyToOne Game` 대신 `gameId`로 참조한다. 공통 게임 애그리거트가 게임별 개념을 알지 않게, 의존이 `twentyquestions → common` 한쪽만 남게 하려는 것이다. 그래서 `revealed_clue.game_id` DB 외래키가 없어졌다.
- 단서 표시 형식은 Mock을 따랐다(관객 수 `약 1,031만 명`, 출연자 앞 5명, 시놉시스 없으면 `정보 없음`). → [API.md 실시간 메시지(STOMP) 규격](../API.md#실시간-메시지stomp-규격)
