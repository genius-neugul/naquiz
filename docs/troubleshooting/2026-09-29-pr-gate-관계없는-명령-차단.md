# PR 게이트가 PR과 관계없는 Bash 명령을 막음

- 날짜: 2026-09-29
- 관련 파일: `.claude/hooks/pr-gate.sh`, `.claude/settings.json`

## 증상

`for` 반복문과 파이프가 들어간 읽기 전용 명령이 "아직 커밋이 없습니다. 먼저 커밋한 뒤 /pre-pr 을 실행하세요."로 막혔다. `gh pr create`와는 관계없는 명령이었다.

## 원인

- `settings.json`은 `"if": "Bash(gh pr create *)"` 조건으로 훅을 건다. 복잡한 명령은 이 조건이 걸러 주지 못하고 훅이 그대로 불렸다.
- `pr-gate.sh`는 훅 입력을 `cat >/dev/null`로 버리고 있어서, 어떤 명령이 들어왔는지 모른 채 항상 PR 조건을 검사했다.
- 그래서 첫 커밋 전에는 "아직 커밋이 없습니다", 커밋 뒤에도 `/pre-pr`을 통과하기 전까지는 "PR 전 점검이 아직 안 됐습니다"로 계속 막혔다.

## 해결

`pr-gate.sh`가 훅 입력에서 `tool_name`과 `tool_input.command`를 읽는다. Bash 명령에 `gh pr create`가 없으면 검사 없이 통과시킨다. MCP `create_pull_request`에는 명령 필드가 없으므로 항상 검사한다. `settings.json`의 `if` 조건은 1차 필터로 그대로 둔다.

## 확인

훅에 샘플 입력을 직접 넣어 실행했다.

| 입력 | 결과 |
|---|---|
| `for` 반복문과 파이프가 들어간 관계없는 명령 | 통과 |
| `git push && gh pr create ...` | 막힘 |
| MCP `create_pull_request` | 막힘 |
