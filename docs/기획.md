#### **일반**

- 로그인 기능 없이 비회원으로만
- 방을 생성하면 초대 코드 생성됨 → 초대 코드를 통해서 방에 입장할 수 있음
    - 내가 아는 사람들끼리만 할 수 있음
    - 초대 코드는 숫자·알파벳 무작위 6자리
    - 방 최대 인원 10명
- 방장이 나가면 방 종료 (방장 위임 없음), 진행 중이던 게임은 승자 없이 끝남
- 연결이 끊기면 재접속 불가 (퇴장 처리)
- 방 안에서 게임을 자유롭게 선택
- 문제 오류가 있는 경우 문제 오류를 입력할 수 있는 부분이 있어야 함
    - 오류 유형: 정답 오류, 힌트 오류, 다른 곡 영상, 원곡 음원 아님(MV·라이브 영상), 그 외
    - 정답 오류면 올바른 정답을 입력할 수 있음

#### **게임 종류**

- 노래 맞추기
- 영화 스무고개
- 스틸컷 보여주고 영화 맞추기

#### **게임 룰**

- 실시간 채팅 형식으로 먼저 채팅을 쳐서 문제를 맞춤
- 문제를 맞출 때마다 1점씩 얻음
    - 게임 시작 전에 방장이 목표 점수 설정해서 목표 점수 도달하면 승리 (최대 50점)
    - 문제를 다 출제하면 이미 나온 문제까지 포함해 매번 랜덤으로 다시 출제해서 반드시 승자가 나옴
    - 게임이 끝나면 방은 대기 상태로 돌아감
- 문제는 완전 랜덤으로 출제
- 라운드 제한 시간 없음
- 정답
    - 정답 처리할 때는 공백 제거
        - Boy With Luv → boywithluv 모두 정답 처리 ⭕
    - 한글, 영문(대소문자 구분 X) 둘 다 정답 가능
        - k-pop의 경우 한글 제목, 영어 제목 따로 만드는 경우가 많음
        - ex) 방탄소년단 – 작은 것들을 위한 시 (Boy With Luv)
            - 작은 것들을 위한 시, Boy With Luv, boy with luv 모두 정답 처리 ⭕
        - ex) 빅뱅 – 뱅뱅뱅 (BANG BANG BANG)
            - 뱅뱅뱅, BANG BANG BANG,  bang bang bang 모두 정답 처리 ⭕
    - feat, ost, duet, prod, ~’s Version 등은 정답 처리 하면 안 됨 ❌
        - 전체 키워드: [MUSIC_PARSING_RULE.md 1-7](MUSIC_PARSING_RULE.md#1-7-부가정보-키워드)
- 투표
    - 힌트나 스킵은 투표로 진행
    - 투표 시간 제한 없음, 인원은 접속 중인 참가자 기준
    - 투표를 연 사람은 자동으로 찬성
    - 참가자가 나가면 줄어든 인원으로 다시 판정
- 힌트
    - 힌트 방식
        - 일정 시간이 지나면 힌트를 보여줌
        - 사용자들끼리 투표
    - 정답 힌트
        - ⚫️ 으로 보여주기 + 글자 수 + 한글, 영문, 숫자, 특수문자 포함 여부
            - 잘 지내자, 우리 → ⚫️ ⚫️⚫️⚫️⚫️ ⚫️ (6글자, 한글 O, 영어 X, 숫자 X, 특수문자 O)
        - 숫자, 특수문자는 한글 영문보다 먼저 보여져야함
            - 잘 지내자, 우리 → ⚫️ ⚫️⚫️⚫️, ⚫️
        - 한글의 경우 초성
            - 잘 지내자, 우리 → ㅈ ㅈㄴㅈ, ㅇㄹ
        - 영어의 경우 랜덤으로 중간중간 아무 문자 보여주기
            - Track 9 → ⚫️r⚫️⚫️k 9
            - 두 글자 이하인 경우 → 한 번에 공개
            - 3으로 안 나눠지는 경우 → 반올림
                - 5/3 →  1.666666… → 2, 7/3 → 2.3333333 → 2
- 스킵
    - 사용자들끼리 투표
        - 2명 이하일 경우, 전부 찬성해야 스킵 가능
        - 3명 이상인 경우, 과반수 이상 찬성해야 스킵 가능

#### 노래 맞추기 퀴즈

- 힌트
    - 순서에 상관없이 힌트 공개 투표 선택 가능
    - 특정 힌트에 대해 ‘공개’ 투표가 통과되면 해당 힌트 오픈 (통과 기준은 스킵과 같음: 2명 이하 전원 찬성, 3명 이상 과반수 이상 찬성)
    - 종류
        - 앨범 힌트(앨범 이미지)
        - 가수 힌트(가수 이름)
        - 발매일 힌트
- 데이터 얻기
    - 노래 리스트(노래 제목 + 가수 데이터 크롤링)
        - 라디오
            - 정오의 희망곡
                - `https://miniweb.imbc.com/Music/View?seqID=1&progCode=FM4U000001226&page=1`
            - 별이 빛나는 밤에
                - `https://miniweb.imbc.com/Music/View?seqID=1&progCode=RASFM210&page=1`
            - 브런치카페
    - 노래 메타데이터
        - Spotify(앨범 이미지, 발매일), YouTube(재생 음원)
        - 초기 데이터는 곡이 많아 미리 조회하지 않고, 출제할 때 없으면 조회해서 저장 (API 호출 제한 방지)

    - 10초 내로 안 하면 패스

#### **백오피스**

- 관리자 로그인
    - 아이디·비밀번호로 로그인, 관리자 계정은 여러 개, 권한 구분 없음
    - 첫 관리자 계정은 DB에 초기 세팅, 로그인 유지는 JWT
- 문제별 통계
    - 어떤 문제를 풀고 어떤 문제를 못푸는지 확인할 수 있어야 함
    - 문제마다 힌트·단서를 얼마나 열었는지
    - 나중에는 완전 랜덤 말고 사람들이 많이 맞추는 문제들이 자주 나오게 확률 높여서
- 힌트 통계
    - 게임 종류별로 어떤 힌트(스무고개는 단서)를 많이 열어봤는지
- 데일리 크롤링
    - 노래(라디오 선곡표)는 매일 새벽 4시에 새 방송을 크롤링해서 곡을 추가
        - 정제 → 이미 있는 곡 제외 → Spotify 조회 → YouTube 음원까지 한 번에 처리
        - Spotify 조회 실패·YouTube 음원 없음인 곡은 오류로 표시돼 검수 필요
    - 프로그램별로 마지막으로 크롤링한 날짜(방송일)와 회차 확인
    - 새로 추가된 문제는 관리자가 검수(승인)해야 출제됨
        - 검수할 때 정답(answer, subAnswer)을 고칠 수 있음
        - 반려하면 출제하지 않음
- 문제 오류 확인·수정
    - 참가자가 신고한 오류 목록 확인 (정답 오류는 신고자가 입력한 올바른 정답도 확인)
    - 출제 중인 문제도 정답을 고칠 수 있음
    - 음원·Spotify 정보가 잘못되거나 없는 곡은 관리자가 직접 입력
    - 문제 정답 수정 또는 비활성화 후 신고를 처리 완료로 바꿈, 잘못된 신고는 반려
