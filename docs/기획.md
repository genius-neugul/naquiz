#### **게임 룰**

- 실시간 채팅 형식으로 먼저 채팅을 쳐서 문제를 맞춤
- 문제를 맞출 때마다 1점씩 얻음
    - 게임 시작 전에 목표 점수 설정해서 목표 점수 도달하면 승리
- 정답
    - 정답 처리할 때는 공백 제거
        - Boy With Luv → boywithluv 모두 정답 처리 ⭕
    - 한글, 영문(대소문자 구분 X) 둘 다 정답 가능
        - k-pop의 경우 한글 제목, 영어 제목 따로 만드는 경우가 많음
        - ex) 방탄소년단 – 작은 것들을 위한 시 (Boy With Luv)
            - 작은 것들을 위한 시, Boy With Luv, boy with luv 모두 정답 처리 ⭕
        - ex) 빅뱅 – 뱅뱅뱅 (BANG BANG BANG)
            - 뱅뱅뱅, BANG BANG BANG,  bang bang bang 모두 정답 처리 ⭕
    - feat, ost, duet, prod, ~’s Version 등은 정답 처리 하면 안 됨 ❌
        - 전체 키워드: [MUSIC_PARSING_RULE.md 1-7](MUSIC_PARSING_RULE.md#1-7-부가정보-키워드)
- 투표
    - 힌트나 스킵은 투표로 진행
- 힌트
    - 힌트 방식
        - 일정 시간이 지나면 힌트를 보여줌
        - 사용자들끼리 투표
    - 정답 힌트
        - ⚫️ 으로 보여주기 + 글자 수 + 한글, 영문, 숫자, 특수문자 포함 여부
            - 잘 지내자, 우리 → ⚫️ ⚫️⚫️⚫️⚫️ ⚫️ (6글자, 한글 O, 영어 X, 숫자 X, 특수문자 O)
        - 숫자, 특수문자는 한글 영문보다 먼저 보여져야함
            - 잘 지내자, 우리 → ⚫️ ⚫️⚫️⚫️, ⚫️
        - 한글의 경우 초성
            - 잘 지내자, 우리 → ㅈ ㅈㄴㅈ, ㅇㄹ
        - 영어의 경우 랜덤으로 중간중간 아무 문자 보여주기
            - Track 9 → ⚫️r⚫️⚫️k 9
            - 두 글자 이하인 경우 → 한 번에 공개
            - 3으로 안 나눠지는 경우 → 반올림
                - 5/3 →  1.666666… → 2, 7/3 → 2.3333333 → 2
- 스킵
    - 사용자들끼리 투표
        - 2명 이하일 경우, 전부 찬성해야 스킵 가능
        - 3명 이상인 경우, 과반수 이상 찬성해야 스킵 가능

#### 노래 맞추기 퀴즈

- 힌트
    - 순서에 상관없이 힌트 공개 투표 선택 가능
    - 특정 힌트에 대해 ‘공개’ 투표가 통과되면 해당 힌트 오픈 (통과 기준은 스킵과 같음: 2명 이하 전원 찬성, 3명 이상 과반수 이상 찬성)
    - 종류
        - 앨범 힌트(앨범 이미지)
        - 가수 힌트(가수 이름)
        - 발매일 힌트
- 데이터 얻기
    - 노래 리스트(노래 제목 + 가수 데이터 크롤링)
        - 라디오
            - 정오의 희망곡
                - `https://miniweb.imbc.com/Music/View?seqID=1&progCode=FM4U000001226&page=1`
            - 별이 빛나는 밤에
                - `https://miniweb.imbc.com/Music/View?seqID=1&progCode=RASFM210&page=1`
            - 브런치카페
    - 노래 메타데이터
        - Spotify
        - iTunes

 

#### **영화 스무고개** ⭐️⭐️

- https://www.kobis.or.kr/kobis/business/stat/boxs/findFormerBoxOfficeList.do
- 관객 수, 개봉일, 감독, 출연자, 시놉시스, 스틸컷, 가능하면 ost, 장르, 제작 나라, 등급
- 스무고개
    - 랜덤으로 순서 정해지고, 순서에 따라 정보 하나씩 클릭해서 오픈
    - 10초 내로 안 하면 패스
- 힌트
    - 정답 힌트(초성 힌트)
        - 스무고개 다 끝나고 열림
        - 1단계 - 글자 수 / 2단계 - 초성 / 3단계부터는 랜덤으로 글자 하나씩 공개

#### **스틸컷 보여주고 영화 맞추기** ⭐️⭐️

- 10초에 스틸컷 하나씩 넘어감
    - 기존 스틸컷 대체
- 모든 스틸컷 다 공개하면 정답힌트(초성)
